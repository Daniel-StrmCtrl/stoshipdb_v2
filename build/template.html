About

Initially made by Reddit user u/wkrick, now rebuilt and maintained by @jalification, using data from the Sortable/Filterable T6 Ship List v2 by Reddit user u/Fleffle.

Note: The total number of ships in this app is higher than the source data because Science Destroyers with Tactical/Science modes are each treated as two distinct ships for more accurate filtering.

Source code: github.com/Daniel-StrmCtrl/stoshipdb_v2. This project is open source — anyone is free to copy, fork, and keep it running. If I'm ever unable to maintain it, please feel free to take it over so the community can keep using it.

⚠️ Heads up: built with AI assistance

Much of this site — especially the Pivot tab — was "vibecoded": built quickly and iteratively with an AI coding assistant. That made it fast to create, but it also means it hasn't been exhaustively tested, and the numbers rely on the source spreadsheet keeping its exact layout. Edge cases may be wrong.

Treat it as a handy fan tool, not a source of truth: enjoy it, but sanity-check anything that matters before you rely on it. Fixes and improvements are welcome on GitHub.
